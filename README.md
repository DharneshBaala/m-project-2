# TaskFlow – Productivity Landing Page

## 📌 Project Overview

TaskFlow is a responsive productivity landing page designed to help users organize their tasks, manage their time, and improve productivity. The website features a clean user interface with a white and orange color theme.

This project is developed as part of **Minor Project 02**.

## ✨ Features

- **Navigation Bar:** Links to different sections of the website.
- **Hero Section:** Introduction to TaskFlow with a call-to-action button.
- **Features Section:** Highlights the main features of TaskFlow.
- **Benefits Section:** Demonstrates how TaskFlow helps improve productivity.
- **Testimonials Section:** Displays sample user reviews.
- **Call-to-Action Section:** Encourages users to get started.
- **Footer:** Contains contact information and useful links.
- **Responsive Layout:** Adapts to different screen sizes using CSS media queries.
- **Modern Design:** White and orange color theme with hover effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- CSS Flexbox
- CSS Grid
- CSS Media Queries

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `html/index.html`.
4. Right-click the file and select **Open with Live Server**, if you have the Live Server extension installed.
5. View the website in your browser.

**Note:** An internet connection is required to load Tailwind CSS through its CDN and any externally hosted images used in the webpage.
